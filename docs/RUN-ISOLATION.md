# 0.6.0：运行产物隔离与验收血缘

[English](RUN-ISOLATION.en.md)

## 修复范围

0.5.0 的项目方法库按工作目录隔离，运行状态按 Session 保存，但媒体读取边界仍是整个 Session 工作目录。**项目隔离、运行状态隔离，不等于文件产物隔离。** 同一工作区中的旧 `production.json`/视频可能通过原有路径检查。这是源码确认的缺口；一次外部对比的同哈希截图/结论，不足以确认该次具体是模型复用、路径错误还是误上传。

0.6.0 对采用媒体 validator 的生产任务（包括三个视频基础流程及继承这些检查的项目 SOP）分配独立产物根目录。编码/部署等就地修改项目的任务不强制迁移源代码。项目库和宿主 Session cwd 保持原身份，不通过修改全局 cwd 造成并发串台。

## 使用

用原服务账号和相同 DSH_HOME 更新，先备份实际状态文件：

```bash
dsh plugin --profile web add github:rffanlab/dsh-playbook#main --force
```

重启原 Profile，开新会话，原任务提示词可以保持不变。视频 route/start 成功后，通过原 DSH bash 执行固定的目录准备程序。创建失败不采用旧目录，也不绕过权限。

```text
<原工作目录>/.dsh-runs/<插件生成的UUID>/
  .dsh-run.json
  brief/
  work/
  evidence/
  artifacts/
  final/
```

每个 run 使用新 UUID。同一任务受控返修仍保留原 run/root/revision 链，而不是伪装成独立模型实验。再做独立实验需要新会话、新 run，不是只切换原会话模型。

模型新增 `playbook(action="workspace")`：准备或查询当前分配目录。正常模型工具入口会自动准备；手动命令启动但没有 live tool token 时，下一次由 Agent 调用此工具。不要求用户手填目录。`status.isolation` 返回根目录及 prepared 状态；用其中的绝对路径建立 production.json，内部相对路径仍以清单所在目录为基准。

媒体任务的 write/edit 只允许指向当前 root；bash 必须显式给当前 root 下的 workdir；直接读取其它 `.dsh-runs` 或已记录旧成品会被拒绝。公用工具可通过明确路径读取/执行，但其本次产物必须写回新 root。未知第三方工具不被假定已经实现文件隔离。

## Gate 检查

检查器接收引擎分配的 ownership，不接受模型在 evidence/旁边 JSON 填的 run_id 作为来源证明。所有清单、口播、源音频、样片、成片、字幕、封面及标题都必须在当前真实 root 内。越界路径、`..`、符号链接、硬链接、被改过的归属标记和明显保留旧修改时间的文件均拒绝。

时间使用准备程序在宿主记录的时间，文件 mtime 仅为辅助信号（保留 2 秒文件系统精度容差）。**复制和 touch 都能产生新时间，因此“文件时间晚于开始”不能证明它是本轮创作。**

最终视频还对照状态中保留的其它 run/candidate 哈希。相同文件即使拷贝进新目录，也不能直接成为一个已验证独立结果。冲突会明确报告 `CROSS_RUN_DUPLICATE`；提交落盘前再次检查，防止并发两轮同时通过。相同字节可能来自确定性生成，本检查标记“独立性未建立”，不据此指控模型抄袭。

已知旧结果尚未在状态里记录时，用户可在 DSH 聊天框登记其 SHA-256：

```text
/playbook exclude-hash <64位SHA256> 旧对照结果，不得作为新结果交付
```

这是当前工作区的人工基线登记，不是模型工具，不能由模型撤销。可以先登记再发实验任务，不改变原任务正文。不扫描和读取整个硬盘来建立基线。未知、从未追踪过的旧文件不会被凭空认出；旧档案只保留每 Session 最近 20 个 run，覆盖范围有限。

## 系统血缘报告

`/playbook report` 和 `export_report` 包含：引擎 run/session ID、分配目录、宿主选用的 provider/model、修订号、验证阶段/时间、实际文件路径、哈希、大小、文件系统修改时间。

`verifiedInStage` 是验收发生阶段，**不是推断的生成阶段**；`verifiedAt` 不是文件出生时间。`creationAttested=false` 明确表示没有证明某个模型亲自生成了字节。同一 run 切换模型会保留 observed routes，不冒充固定模型独立实验。系统报告在产物旁保存这些事实，模型自行写一个同名 sidecar 不参与 Gate。

## 不作过度承诺

本版是**产物归属/验收隔离，不是进程级文件访问沙箱**。Shell 使用当前 workdir 仍可能通过绝对路径读到其它文件；`run_code`、第三方服务和任意代码也不能靠工具名检查全面封锁。真实防读取需在 Harness/操作系统提供仅可见当前 run 与明确公共输入的独立沙箱。没有改用户系统权限、未静默容器化、没有过滤或移动用户上下文。

哈希可识别已知完全相同的文件，无法识别重新编码或修改后的语义复制；时间戳和作者标签同样不能独立证明来源。本版仍无 ASR，不证明逐字口播或创作质量。需要模型生成轨迹和最终文件的关联才能进一步归因。

## 迁移与测试

状态仍为 v3，新增可选的 run.isolation 与工作区输出排除表；升级前备份，回退前恢复相应备份。既有未隔离 run 不自动换目录、复制旧产物或补写新作者；其媒体 validator 会提示需要新任务，不能把旧执行包装成新独立实验。旧状态中已有候选哈希仍可用于对照。

回归使用匿名合成夹具，不上传私人视频、模型 session 或用户哈希。Node 测试覆盖分配、归属、同哈希换路径、并发、宿主权限链、项目身份不变、已知旧哈希和报告口径。Python/FFmpeg 测试覆盖实际创建、不接管旧目录、链接/路径/标记/时间和真实媒体解码。

尚未在用户 E5 上或真实 MiniMax/Flash 端到端运行。不能用 CI 通过声称本次历史污染链已经定位或下一轮模型质量一定改善。
